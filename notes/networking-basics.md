## Module 1: Communication in a Connected World

- The internet is not owned by one person or company. It is a worldwide network made from many connected networks.
- Volunteered data is data I choose to give, like uploading a photo, video, form, or message.
- Inferred data is guessed or calculated from other data, like a credit score.
- Observed data is collected by tracking activity, like location, clicks, or device usage.
- Bits are binary values: 0 and 1.
- Kbps means thousands of bits per second, Mbps means millions, and Gbps means billions.
- Data can travel through fiber optic cables using light pulses, wireless using radio waves, or copper cables using electrical signals.
- Bandwidth is the maximum capacity of a connection.
- Throughput is the actual data successfully transferred, and it can be lower than bandwidth.
- Latency is the delay between sending and receiving data.

## Module 2 — Network Devices and Connections

### Main ideas

- A **host** is any device on a network that can send or receive data.
- A **server** is a host that provides a service to other devices.
- A device can be a **client**, a **server**, or both depending on what it is doing.
- A **client** requests a service.
- A **server** provides a service.
- All servers are hosts, but not all hosts are servers.
- **Peer-to-peer**, or P2P, means devices communicate directly with each other instead of relying on one central server.
- P2P networks can be easy to set up, but they are harder to manage and secure.
- In P2P, each device may request resources and also provide resources.
- **End devices** are devices that send or receive data, like computers, phones, printers, cameras, and servers.
- **Intermediary devices** connect devices and move traffic between networks.
- Examples of intermediary devices include switches, routers, wireless access points, and firewalls.
- An **ISP**, or Internet Service Provider, connects a home or business network to the internet.

### Host vs server

A host is any device on a network with a network address that can send or receive data.

A server is a host that provides a service to other devices.

Examples:

- Phone on Wi-Fi = host
- Laptop on Wi-Fi = host
- Printer on Wi-Fi = host, and it can also act like a print server
- Website server = host and server

Rule:

> All servers are hosts, but not all hosts are servers.

### Client vs server

A client requests a service.

A server provides a service.

Example:

- My computer opens a website, so my computer is the client.
- The website server sends the webpage, so it is the server.

### Peer-to-peer networks

Peer-to-peer means devices communicate directly with each other.

In a P2P network, devices can act as both clients and servers. For example, one computer can request a file while also sharing a file with another computer.

P2P can be useful because it is simple and does not always need a central server. However, it can be harder to secure because there is no central system controlling users, permissions, updates, and access. Each device is more responsible for its own security.

### End devices

End devices are the devices that create, send, or receive data.

Examples:

- Computer
- Phone
- Printer
- Camera
- Server

### Intermediary devices

Intermediary devices help move data between end devices and networks.

Examples:

- Switch
- Router
- Wireless access point
- Firewall

A router is an intermediary device because it moves traffic between networks.

### Internet connection types

Different homes and businesses can connect to the internet in different ways.

- **DSL** uses telephone lines and is usually slower than cable or fiber.
- **Cable internet** uses cable TV infrastructure and is usually faster than DSL.
- **Fiber optic** uses light through fiber cables and is usually very fast and reliable.
- Connection quality depends on what infrastructure is available in the area.

### Module 3 Wireless and Mobile Networks

### was about common ways devices connect to networks and to each other. Most modern devices have built-in wireless options like 
Wi-Fi and Bluetooth.

Wi-Fi is used to connect a device to a wireless network, usually through a router or access point. To join a Wi-Fi network, you usually need to know the SSID, which is the network name, and the password/security key.

Bluetooth is different because it is usually used for short-range connections between devices, like headphones, speakers, keyboards, mice, phones, or cars.

The main idea is that devices need some type of connection method before they can communicate or access network resources. For cybersecurity, this matters because every connection method can involve security settings, passwords, encryption, and possible risks if it is configured badly.
